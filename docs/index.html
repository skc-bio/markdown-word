导出后就是一个可以直接打开、翻页、全屏的网页

HTML 导出会保留分页展示体验，不需要重新做 PPT。适合课堂展示、组会分享、临时演示，也方便把一份笔记发给没有 Obsidian 的人直接在浏览器里看。

  • 方向键、Space、PageUp / PageDown 翻页
  • 按 F 进入 / 退出全屏
  • 自动按浏览器窗口缩放页面
  • 保留页面尺寸、公式、图片、文本框和图形布局

如果需要继续编辑演示稿，可导出 PPTX；如果需要固定版式交付，推荐可复制矢量 PDF。

PDF
可复制矢量精确页面尺寸、正文可搜索、MathJax 字形修复。
PPTX
继续演示编辑文本、图片、表格与图层尽量保持可编辑。
DOCX
流式 Word 文档适合作业、报告和进一步文字修改。
HTML
独立分页放映浏览器打开即可翻页、缩放与全屏。
MD
保留原始内容用于知识库、版本管理、迁移和复用。
