Markdown Word 实用指南

3 分钟快速开始

下载插件压缩包例如 markdown-word-0.9.3.zip。不要直接把 ZIP 丢进插件目录，要先解压。
找到你的 Obsidian Vault打开这个知识库所在的真实文件夹，进入隐藏目录 .obsidian/plugins/。
放入插件文件夹最终路径应该是 .obsidian/plugins/markdown-word/，里面直接能看到 main.js、manifest.json、styles.css。
重启 Obsidian 并启用进入 设置 → 第三方插件 / Community plugins → 找到 Markdown Word → 开启。
打开一篇 Markdown 笔记通过命令面板、左侧按钮或文件菜单打开 Markdown Word 页面模式。
判断是否安装正确：Obsidian 插件列表中能看到 “Markdown Word”，并显示作者 Su & ChatGPT；打开页面模式后顶部出现格式工具栏，正文显示在分页纸张上。

完整安装教程

1. 下载并解压 ZIP

下载类似下面这样的压缩包：

markdown-word-0.9.3.zip

解压以后应得到一个名为 markdown-word 的文件夹。最重要的是确认不要多套一层目录。

2. 找到 Vault 的插件目录

Obsidian 的插件是按知识库（Vault）安装的。假设你的知识库叫“日记”，目录结构大致如下：

日记/
├─ .obsidian/
│  ├─ plugins/
│  │  └─ markdown-word/
│  │     ├─ main.js
│  │     ├─ manifest.json
│  │     ├─ styles.css
│  │     └─ README.md
├─ 笔记1.md
└─ ...
Windows 用户：.obsidian 可能是隐藏文件夹。资源管理器 → 查看 → 显示 → 隐藏的项目。macOS 可在 Finder 中按 ⌘ + Shift + . 显示隐藏文件。

3. 正确的最终路径

你的 Vault/.obsidian/plugins/markdown-word/main.js

如果变成了下面这样，就多嵌套了一层：

❌ .obsidian/plugins/markdown-word/markdown-word/main.js

4. 在 Obsidian 中启用

  1. 完全关闭并重新打开 Obsidian。
  2. 设置 → 第三方插件 / Community plugins。
  3. 如果处于 Restricted Mode / 安全模式，先允许第三方插件。
  4. 找到 Markdown Word。
  5. 打开右侧开关。

更新插件

手动安装版本最稳妥的更新方式是整文件夹替换：

关闭 Obsidian避免旧的 main.js 正在被占用。
备份旧目录可将 markdown-word 临时改名为 markdown-word-backup。
删除旧目录并放入新版不要只覆盖某一个文件，避免新旧代码混杂。
重新打开 Obsidian到插件列表确认版本号已变化。
你的笔记不会存在插件目录里。正文仍是 Vault 中的 .md，页面布局通常保存在对应的布局数据文件中，所以替换插件程序本身不会删除正文。

如何进入 Markdown Word

先打开一篇普通 .md 笔记，再通过以下任一入口进入页面模式：

  • 命令面板搜索 Open current note in page mode / Markdown Word。
  • 点击插件提供的 Ribbon / 左侧按钮。
  • 在文件菜单中选择用 Markdown Word 打开。

插件会尽量复用已经打开的 Markdown Word 标签页，避免同一文件反复产生重复标签。

正文：像 Markdown 一样写，像文档一样看

Markdown Word 的正文仍以 Markdown 为底层。平时看到的是渲染后的页面；进入某一段编辑时，会编辑该段 Markdown 源码，离开后重新显示最终效果。

标题

# 一级标题
## 二级标题
### 三级标题

强调

**粗体**
*斜体*
~~删除线~~
`行内代码`

在任意位置插入新行

把鼠标移到正文左侧边缘，会出现跟随当前行/块位置的 +。点击即可在对应位置插入新的 Markdown 段落。

这适合已经排好一页之后，在中间补充解释，而不需要跑回原始 Markdown 文件找位置。

公式

行内公式

速度满足 $v = \frac{dx}{dt}$，因此……

块公式

$$
\int_a^b f(x)\,dx
$$

常见 LaTeX 写法都可以继续使用，例如 \frac、\sqrt、上下标、希腊字母、求和、积分、矩阵等。

Office 导出：常见公式会尽量转换成 Word / PowerPoint 的原生 Office Math（OMML），因此在支持的 Office 中可以继续编辑。非常复杂或不支持的 LaTeX 会使用高质量 fallback，避免整份文件导出失败。
PDF（0.9.31）：推荐的“可复制矢量 PDF”会保留正文文字层，并在导出前物化 MathJax 字形，解决部分数学变量（如 n、x、i、n²）在 PDF 中消失的问题。页面尺寸直接使用插件设置的 mm 宽高。

表格

可以从顶部工具栏插入表格。页面中的表格支持直接编辑单元格，并提供类似 Obsidian 的扩展按钮：

  • 表格右侧 +：增加一列。
  • 表格底部 +：增加一行。
  • 表头列边缘的 +：从中间插入新列。
  • 直接点击单元格文字即可修改。
| 列 1 | 列 2 |
| --- | --- |
| 内容 A | 内容 B |

PPTX / DOCX 导出时，表格会尽量生成原生 Office 表格，而不是整块截图。

图片

图片是独立浮动对象，可以像 PPT 一样移动和调整大小。

添加图片

  • 点击顶部 + 图片，选择 Vault 中已有图片。
  • 也可以在支持的场景中直接复制 / 粘贴图片。

引用 Vault 已有图片时，插件尽量只记录引用和布局，不为了排版额外复制一份图片文件。

图片常用操作

单击图片选中；右键可打开操作菜单：

复制剪切置于顶层置于底层删除

选中后还可以直接按 Delete / Backspace 删除。

文本框

文本框是一种独立图层，适合旁注、重点说明、图旁解释、补充结论。

  • 单击：选中 / 拖动文本框。
  • 双击：进入文本编辑。
  • 文本框内部同样可以使用 Markdown 和顶部格式工具。
  • 右键：复制、剪切、置顶、置底、删除。
如果你要移动文本框，直接单击后拖；如果你要改字，双击。这能避免“想拖动却突然出现光标”。

箭头与方框

箭头

点击 → 箭头 后，在页面上按住起点，拖到终点，松手生成。选中后可以继续拖动两端控制点。

方框

点击 □ 方框 后，从一个角拖到另一个角。选中后可以通过控制点调整宽高。

图形支持颜色、线宽、层级、复制、跨页、锁定等操作。

连续绘制：双击绘图工具可保持绘图状态；按 Esc 退出绘图模式。

多选、框选与图层

Shift 多选

按住 Shift，依次点击图片、文本框、方框、箭头，可以加入或移出当前选择。

框选

在页面空白区域按住鼠标拖出矩形框，可一次选择多个浮动对象。

整组拖动

多选后，拖动其中任意一个已选对象，同一页内的整组选中对象会一起移动。

目前整组拖动以同页对象为主，避免不同页面坐标系造成不可预测的跨页移动。

点击空白处

点击页面空白区域可清除当前对象选择。

页面、顺序与尺寸

页面预览侧栏

点击顶部 页面 可打开侧栏：

  • 点击缩略图跳转页面。
  • 拖拽缩略图调整页面顺序。
  • 复选多个页面后批量删除。
  • Shift 可进行连续页选择。

新增页面

使用顶部 + 页，会在当前页后面增加新页。后来页面上的图片、文本框、图形会随原页面一起后移。

正文编辑中也可以使用 Ctrl/Cmd + Enter 进行显式分页。

两种“缩放”不要混淆

功能作用是否影响导出尺寸
视图缩放只是把纸张在屏幕上放大 / 缩小否
页面物理尺寸真正改变宽、高 mm，并保持比例是

你可以选择 A4 / 横向等预设，也可以直接输入宽高 mm，或者使用物理尺寸滑块按当前比例整体放大 / 缩小页面。

导出

顶部右侧提供常见导出入口：

PDF

推荐使用“可复制矢量 PDF”：正文保留为可选择、可复制、可搜索的 PDF 文字；页面尺寸直接使用插件中的实际 mm 宽高；MathJax 公式会在导出前物化字形以减少变量丢失。PDF 菜单同时保留系统打印兼容模式和 4× 超清图片 PDF。

PPTX

正文、图片、文本框、箭头、方框尽量保持独立对象；表格使用 PowerPoint 原生表格；常见公式尝试 Office Math。

DOCX

适合生成流式 Word 文档。表格是 Word 原生表格；常见公式尽量转换为 OMML 原生公式。

HTML

导出一个独立的分页放映网页。方向键 / Space / PageUp / PageDown 翻页，F 全屏，并会根据浏览器窗口自动缩放页面。适合课堂、组会和快速分享。

MD

导出 Markdown 文本副本，适合长期保存、版本管理、迁移与复用。

导出建议：如果某个复杂公式在 PDF 中视觉效果不理想，而 PPTX 中效果很好，可以先导出 PPTX，再由 PowerPoint / WPS 导出 PDF。这是很实用的备用流程。

推荐的实际笔记工作流

先写内容快速输入标题、公式、正文、列表，不要一开始就追求每个元素的位置完美。
再分页把一大段内容切成适合阅读、复习或展示的页面。
再加视觉解释插入图片、文本框、箭头、方框，用空间位置表达“这张图解释这段话”。
最后导出课程笔记留在 Obsidian；交作业可 DOCX/PDF；演示可直接用 HTML，也可以导出 PPTX 继续编辑。
这样做的好处是：原始 Markdown 始终留在知识库里，排版只是它的一层表现。以后要重写、搜索、复用内容，不需要从截图或 PPT 里反向抄回来。

常见问题与排查

插件提示“加载失败”

  • 检查最终路径是不是 .obsidian/plugins/markdown-word/main.js。
  • 确认 manifest.json、styles.css 与 main.js 在同一级目录。
  • 完全退出 Obsidian 再打开。
  • 不要把 ZIP 本身直接放进 plugins 文件夹。

更新了但感觉还是旧版

  • 关闭 Obsidian。
  • 把旧 markdown-word 目录整个删除。
  • 重新复制新版目录。
  • 打开插件设置确认版本号。

图片 / 文本框移动后插页错位

新版已经针对“前面插入页面后浮动对象没有跟着原页面后移”做了处理。如果仍出现，优先确认是否真的运行的是最新版。

公式导出和页面显示略有差异

页面内公式由 Obsidian / MathJax 渲染；Office 使用自己的公式系统。常见公式可以转换，复杂宏的字体度量与排版仍可能不同。需要绝对视觉一致时，PPTX 的 fallback 或 PPTX → PDF 往往最稳。

快捷键被其他插件抢走

打开 Obsidian 设置 → 快捷键，搜索 Markdown Word 相关命令，检查是否与其他插件冲突。

备份与安全建议

  • 定期备份整个 Vault，而不仅是插件文件夹。
  • 大改笔记前可以复制一份 .md 作为快照。
  • 布局信息与 Markdown 正文是不同层次的数据，两者都建议随 Vault 一起备份。
  • 插件升级前保留旧 ZIP，遇到兼容问题可以快速回退。
  • 重要作业 / 报告导出后，用目标软件实际打开一次确认公式、表格和图片。

一句话记住它怎么用

Markdown 负责内容，页面负责空间，图层负责解释，导出负责交付。
