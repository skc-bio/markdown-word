Standalone HTML keeps the paged presentation experience, so a note can be shown without rebuilding it in PowerPoint. It is useful for classes, lab meetings, quick talks, and sharing with people who do not use Obsidian.

  • Arrow keys, Space, PageUp / PageDown for navigation
  • Press F to enter or leave fullscreen
  • Automatic fit-to-window scaling
  • Keeps page size, equations, images, text boxes and layout

Use PPTX when you need to keep editing slides, or selectable vector PDF when you need a fixed deliverable.
