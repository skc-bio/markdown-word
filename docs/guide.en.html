Markdown Word User Guide

Installation, page mode, Markdown, layers, equations, pagination, and export.

Install

  1. Download the latest ZIP from GitHub Releases.
  2. Extract the markdown-word folder into Your Vault/.obsidian/plugins/.
  3. Make sure main.js, manifest.json, and styles.css are directly inside that folder.
  4. Restart Obsidian and enable Markdown Word under Settings → Community plugins.
Your Vault/
└─ .obsidian/
   └─ plugins/
      └─ markdown-word/
         ├─ main.js
         ├─ manifest.json
         └─ styles.css

Open page mode

Open any .md note, then use the command palette, ribbon entry, or file menu to open it in Markdown Word page mode.

Markdown and equations

The body remains Markdown. Use $...$ for inline equations and $$...$$ for display equations. Common LaTeX constructs such as fractions, roots, subscripts, superscripts, Greek letters, sums, integrals, and matrices continue to work through MathJax.

Images, text boxes, and shapes

  • Images, text boxes, arrows, and rectangles are independent layout objects.
  • Use Shift-click or marquee selection for multi-select.
  • Drag a selected object to move a group on the same page.
  • Right-click objects for common actions such as copy, delete, ordering, and lock/unlock.
  • Text boxes support their own font and line-spacing settings.

Pages and physical dimensions

Pages can use presets such as A4 or custom width/height in millimetres. Physical page size affects export; view zoom only changes how large the page appears on screen. You can also adjust page margins and base body text size.

PDF export

Selectable vector PDF (recommended) preserves body text as real PDF text, respects the exact page size configured in Markdown Word, and materializes MathJax generated glyphs before export to avoid missing variables such as n, x, i, and n².

The PDF menu also includes a system-print compatibility mode and a 4× high-resolution image PDF fallback.

PPTX / DOCX / HTML / MD

  • PPTX: keeps text, images, tables, text boxes, and shapes editable where possible; common equations are converted to Office Math when possible.
  • DOCX: produces a flowing Word document with native tables and common equations where possible.
  • HTML: exports a standalone paged presentation with keyboard navigation, scaling, and fullscreen mode.
  • MD: exports/keeps the Markdown source for portability and version control.

Recommended workflow

  1. Write content first in Markdown.
  2. Arrange figures and annotations.
  3. Refine pagination, page size, margins, and object positions.
  4. Export only at the end, and verify important deliverables in the target application.

Troubleshooting

  • If the plugin fails to load, verify the folder nesting and restart Obsidian completely.
  • If an update still looks old, remove the previous plugin folder and copy the new one again.
  • For important work, back up both the Markdown and its layout data.
  • Third-party themes, unusual fonts, or very complex Office equations can still produce small visual differences.
