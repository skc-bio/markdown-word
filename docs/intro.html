Markdown Word · Obsidian 插件

在“页面”上写 Markdown。

Markdown Word 想解决一个很具体的问题：Markdown 很适合快速记录和结构化知识， Word / PPT 很适合页面排版和图文布局，但二者长期分属于两套工作流。 这个插件试着把它们合在一起——让你继续用 Markdown 思考，同时在真正的纸张页面上完成笔记。

它和传统笔记的差别，不只是“多一个 Markdown 编辑器”

核心变化是：内容结构与视觉布局同时存在。你不必先写完，再去另一个软件排版。

01

Markdown 负责“想法”

标题、列表、公式、表格、强调等内容仍用 Markdown 表达。输入快、结构稳定，也更适合长期积累。

02

页面负责“空间”

笔记不再是一条无限向下的文本流。页面有真实尺寸，可以按 A4 或自定义比例组织内容。

03

图层负责“解释”

图片、文本框、方框、箭头可以作为独立对象拖动、叠放、多选和调整，更适合理工科图文混排。

04

公式属于笔记本身

LaTeX 公式直接写进 Markdown，不需要截图公式再贴回来；导出 Office 时还可以尽量转换为原生公式。

05

一次记录，多种输出

同一份笔记可以继续保留为 Markdown，也能导出 PPTX、DOCX、PDF，减少“重新做一遍”的工作。

06

仍然属于 Obsidian

文件继续留在 Vault 中，而不是被锁进新的专有格式。原始 Markdown 仍是知识库的一部分。

与传统笔记工具相比

它并不试图彻底替代 Word、PPT 或纸笔，而是把各自最适合做笔记的部分放到一条工作流里。

更适合这种笔记流程

尤其适合“内容密度高、公式多、图片多、最后还要交作业 / 做展示”的场景。

1. 先记 用 Markdown 快速记录定义、公式、推导与结论。
2. 再摆 把图、文本框、箭头拖到最适合解释内容的位置。
3. 再整理 分页、调整页面尺寸、重排对象、补充注释。
4. 直接输出 继续留在 Obsidian，或导出成 PPTX / DOCX / PDF。
“它更像一个以 Markdown 为底层语言、以 Word/PPT 为视觉界面的笔记本。” Markdown Word 的目标不是让 Markdown 变复杂，而是让排版不再打断思考。

它真正想解决的，是工具切换

很多人的实际流程是：Obsidian 写内容 → 截公式 → Word 整理 → PPT 再排一次 → PDF 再导一次。 每切一次工具，就会重复复制、粘贴、改格式、调图片位置。

Markdown Word 希望把这条流程压缩成一个文档：输入时像 Markdown，阅读时像排版文档， 调图时像 PPT，最终仍然能回到 Markdown。 对于长期做学习笔记、课程笔记、研究笔记和技术文档的人，这种“同一份内容，多种形态”的工作方式， 往往比单纯追求某一种编辑器更重要。
