v0.9.31 · Obsidian plugin

Write Markdown on real pages.

Markdown Word brings Markdown structure, Word-like physical pages, and PowerPoint-like freeform layers into one Obsidian workflow. Version 0.9.31 adds selectable vector PDF, more reliable MathJax export, and standalone presentation HTML.

What is it now?
  • A paged note editor with Markdown as the content layer
  • A visual layout tool with independent floating objects
  • A delivery tool that exports the same note to PDF / PPTX / DOCX / HTML / MD

The problem it tries to solve

Technical notes often need both structure and space: headings, lists, and equations work well in Markdown, while figures, annotations, side notes, and fixed pages need a Word/PPT-like visual layout. Traditional workflows often force you to reformat the same content across several tools.

01

Markdown handles content

Body text, headings, lists, emphasis, tables, and LaTeX stay as searchable, versionable Markdown.

02

Pages handle space

Pages have physical dimensions, margins, and base text size instead of being an endless vertical stream.

03

Layers handle explanation

Images, text boxes, arrows, and rectangles behave like independent PowerPoint-style objects.

04

PDF handles reliable delivery

The recommended PDF path preserves selectable text and uses the exact physical page size configured in the plugin.

05

Equations belong to the document

MathJax equations do not need to be screenshots; 0.9.31 fixes missing variable glyphs in vector PDF export.

06

One note, many forms

Use HTML/PPTX for presentation, PDF for print/delivery, DOCX for a flowing Word document, and MD for portability.

Compared with traditional tools

It does not try to replace every detail of Word or PowerPoint. Its goal is to reduce the work of rebuilding content that already exists.

Export philosophy in 0.9.31

Each target format gets the representation that fits it best: PDF prioritizes selectable text and vector equations; Office export keeps objects editable where possible; fallbacks protect visual fidelity; HTML preserves the paged presentation experience.

“Markdown handles content, pages handle space, layers handle explanation, and export handles delivery.”That is closer to the goal of Markdown Word than simply “another Markdown editor.”

Recommended workflow

1. Write firstCapture content, equations, and conclusions quickly in Markdown.
2. ArrangePlace figures, text boxes, and arrows where they explain best.
3. RefineAdjust pagination, physical dimensions, margins, text size, and layer order.
4. DeliverExport to PDF / PPTX / DOCX / HTML / MD as needed.

Current status

Markdown Word is still a fast-moving desktop plugin. Complex Office equations, extreme CSS styling, third-party themes, and unusual fonts may still differ slightly from the Obsidian page. Important exports should be checked once in the target application.
